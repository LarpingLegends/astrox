# AstroX

Jeu éducatif en français sur les planètes du système solaire.

Pages principales :
- `index.html` : système solaire interactif
- `tutoriel.html` : fiches de révision
- `mercure.html` à `neptune.html` : 8 quiz de 5 questions

Les quiz utilisent `quiz.css` pour le design commun et `quiz.js` pour les questions, le score, les corrections et la fusée de progression.
